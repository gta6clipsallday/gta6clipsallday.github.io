GTA6 Clipper

GTA6 Clipper is a personal tool that turns GTA 6 gameplay streams into short vertical clips and uploads them to the owner's own YouTube channel as YouTube Shorts.

What it does

  • Finds highlight moments in a stream and cuts them into 9:16 clips with captions.
  • Uploads each clip to the signed-in user's YouTube channel with a title, description, hashtags and thumbnail, using the YouTube Data API.

It runs only on the owner's own computer. It is not a public service and has no user accounts.

Privacy Policy

Uses YouTube API Services. See the YouTube Terms of Service.
